# 学习城市建设者 ✨

> AI-powered learning planner with constellation-themed achievements

将抽象的学习目标拆解为可执行的每日任务，配合星座成就系统让坚持变得可视化。

🔗 **[在线体验](https://xavierdon395-code.github.io/learning-city-builder/)**

## ✨ 核心功能

- 🤖 **AI 智能拆解** —— DeepSeek V3 生成大纲 + 7 天滚动窗口动态调整难度
- 🌟 **12 星座成就星图** —— 50 个徽章 / 158 颗星，按白羊到双鱼顺序点亮
- 📊 **灵活时间管理** —— 统一/分天模式，请假暂停超 20% 不计成就
- 🏆 **多维度统计** —— 完成率、连续打卡、月度报告、AI 周复盘
- ☁️ **云端同步** —— Firebase Realtime Database 多设备无缝切换
- 🎨 **深空星座主题** —— 极简毛玻璃 UI，金色 + 黑白灰阶克制配色

## 🛠️ 技术栈

| 层 | 技术 |
|---|---|
| 前端 | Vanilla HTML / CSS / JavaScript |
| 认证 & 数据 | Firebase Authentication + Realtime Database |
| AI | DeepSeek V3 API |
| 部署 | GitHub Pages + Vercel |
